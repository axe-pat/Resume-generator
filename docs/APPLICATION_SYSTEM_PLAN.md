# Akshat — Full Application System Plan
*Created: March 2026 | Status: Planning → Build*

---

## What Exists Today (Foundation)

`ResumeGenerator v1/` — a working, production-quality resume generator:
- **Input:** A `.txt` JD file
- **Output:** A tailored one-page `.docx` resume + `.txt` analysis file
- **Core:** `freeform_runner.py` calls Claude with a master prompt + bullet bank → selects 11 bullets across 4 companies → generates SKILLS & INTERESTS → runs 9 QC checks → auto-selects layout tier for single-page fit → renders `.docx` via `resume_docx.js` (Times New Roman, Symbol bullets, justified, auto-tiered spacing)
- **Run command:** `python freeform_runner.py <jd_name> --docx`

---

## The Vision

A fully automated application pipeline that:
1. **Finds** new PM (and other target) roles online every 12h
2. **Ranks** them by fit
3. **Generates** a complete application package (resume + cover letter + strategy note) for each
4. **Organises** them into local folders with priority sorting
5. **You review**, approve, and apply
6. *(Later)* **Reaches out** to relevant LinkedIn contacts for each role

---

## Stage 1 — Job Discovery Pipeline
**Goal:** Pull new roles every 12h, deduplicate, store, rank by fit.

### Components
- **Scrapers:** LinkedIn job search (filtered by role type, experience level, location), Handshake (USC-specific), direct Greenhouse/Lever/Workday crawls for a curated company watchlist
- **Database:** SQLite — `jobs` table with: `id`, `url`, `company`, `role_title`, `jd_text`, `date_found`, `status` (new / queued / generated / applied / skipped), `fit_score`, `fit_rationale`, `url_hash` (for dedup)
- **Deduplication:** Hash-based on URL + title+company combo
- **Role filtering:** Configurable target role types (PM Intern, Associate PM, Strategy & Ops, Growth, etc.), seniority filters, location filters, company blocklist
- **Fit scoring:** Claude scores each new JD 1–10 against Akshat's background, outputs a 2-sentence rationale. Considers: MBA internship framing, tech/growth/enterprise theme overlap, location, company tier

### Outputs
- Populated SQLite DB with new roles marked `status=queued` and sorted by `fit_score`

**Estimated build time:** 1.5–2 weeks

## Stage 2 — Application Package Generation
**Goal:** For each queued role, generate a complete application folder.

### Directory Structure
```
applications/
  [9.2]_2026-03-19_Rubrik_MBA-Intern-Monetization/
    job.json           ← metadata (URL, score, rationale, date, status)
    jd.txt             ← raw JD text
    resume.docx        ← generated by freeform_runner.py
    cover_letter.docx  ← generated by CL generator (new)
    note.md            ← strategic reasoning (new)
```

### Components

**Resume** — already done. Wire JD into `freeform_runner.py --docx`.

**Cover Letter** — new Claude prompt:
- 3 paragraphs: (1) hook tied to top JD signal + why this company specifically, (2) 2 story references with different framing than the resume, (3) forward-looking close
- Rendered as matching `.docx` (same TNR styling as resume)
- ~250–300 words

**Application Note (`note.md`)** — new Claude prompt, ~300 words:
- Why this role/company is a strong fit for Akshat specifically
- Resume strategy: which stories were selected, which variants, why they work for this JD
- Cover letter angle: what hook was chosen and why
- Risks or gaps to be aware of
- Optional recommendations (people to reach out to, additional tailoring suggestions, things to mention in the interview)

**Folder naming:** `[{score}]_{date}_{company}_{role-slug}/` — scores prefix ensures Finder/Explorer sorts by priority naturally.

### Outputs
- One folder per role, fully populated
- `status` updated to `generated` in DB

**Estimated build time:** 1–1.5 weeks

## Stage 3 — Orchestrator & Scheduler
**Goal:** Tie stages 1–2 into a single automated pipeline on a 12h cron.

### Components
- **Orchestrator script** (`orchestrator.py`):
  1. Run scrapers → insert new jobs into DB
  2. Deduplicate
  3. Score + rank new roles
  4. For roles above fit threshold (e.g. ≥ 6.5), generate application package
  5. Update DB status
  6. Write daily digest: N new roles found, N packages generated, top 3 by score
- **Scheduler:** 12h cron (via Claude's schedule skill or system cron)
- **Error handling:** Failed generation stays `queued`, retries next run. Scraper failures log and continue.

**Estimated build time:** 0.5 weeks

## Stage 4 — Review Interface
**Goal:** When you open your machine, immediately know what to look at and in what order.

### Components
- **Folder sorting:** Score prefix handles Finder/Explorer ordering automatically
- **`note.md`:** Designed to be scannable in 60 seconds — the first thing you read
- **Master tracker (`tracker.xlsx`):** One row per role — company, role, score, status, date applied, notes — auto-updated by orchestrator after each run
- **Daily digest:** Printed to terminal on orchestrator run (or optionally pushed as a macOS notification)

### Review flow
1. Open `applications/` — folders sorted by score descending
2. Open top folder's `note.md` — read the 60-second brief
3. Open `resume.docx` + `cover_letter.docx` — review and approve
4. Apply → update `tracker.xlsx` → mark `status=applied` in DB

**Estimated build time:** 0.5 weeks

---

## Stage 5 — LinkedIn Outreach *(last piece)*
**Goal:** For each role you apply to, identify and message 1–3 relevant LinkedIn contacts.

### Components
- **Contact discovery:** Given company + role, find: USC Marshall alums at that company, 1st/2nd degree connections with PM/recruiting titles
- **Outreach message generation:** Claude writes a short personalised note per contact — references shared school or connection, mentions the specific role, asks for a 15-min chat (not a referral ask)
- **Rules system:** Configurable — reach out only if fit score ≥ 7, USC alums always first, don't re-message within 90 days, max 20–30 requests/day (LinkedIn rate limit)
- **Sending:** Automated via LinkedIn (Selenium/Playwright; auth managed carefully)
- **Tracking:** Outreach table in DB — who was contacted, when, response status, follow-up needed

**Estimated build time:** 2–3 weeks
